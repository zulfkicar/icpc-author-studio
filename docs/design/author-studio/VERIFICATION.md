# Author Studio verification

## Scripted workflow

The scripted sample exercises the local chat, editor and package backend with
synthetic problem data. The browser checks covered draft recovery, keyboard
navigation, narrow layouts, evidence inspection, concurrent saves, job
reconnection, and exact-snapshot export approval. The package runner and
verifier used installed tools. A separate DOMjudge 9.0.1 import accepted the
sample statement and two cases.
[Studio release checks](../product-experience/RELEASE-4.md)

## Live checks

Separate local trials used DeepSeek Flash through OpenRouter. One trial went
from a browser conversation to a verified DOMjudge ZIP. Another exercised a
real mismatch through Isolate, one model-generated repair, and a passing
replay on the same independent tests. The app kept export behind human
review. The trials establish those journeys on the tested setup. They leave
provider breadth, performance across problems, and independent author
qualification open.

## Weighted scheduling campaigns

The T34 tests use scripted planning and a real local Isolate worker for
three compiled journeys. They cover a strict-endpoint counterexample,
agreement when the author chooses closed intervals, and agreement from a
correct sweep-line implementation on the half-open sample. The reports bind
the input bytes, decisions, independent expected results and source hash.
[T34 contract and test commands](../../implementation/T34-WEIGHTED-CAMPAIGNS.md)
