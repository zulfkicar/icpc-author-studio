# Formative setter sessions

Recruit three to five setters with a mix of chat-led and existing-package
experience. Use a disposable workspace for each participant. Start with one
person in each path, then vary familiarity and screen size. Leave the order
evenly balanced if participants try both paths.

Before starting, explain the task, what will be observed, and that taking part
is voluntary. Ask before recording. Participants can pause or stop and can
review any notes that might identify them. Use the sample and the synthetic
manual package so the session needs no contest material or provider credentials.

| Task | Observable completion | Record |
| --- | --- | --- |
| Start a chat-led problem | Explain the endpoint choice, open the counterexample in Run, fix the reference, and approve the verified package | Whether the setter identifies the simulation and the real process result, where they hesitate, and how long the recovery takes |
| Open existing work | Reopen a saved file, run one case, verify the package, and return to the same place after switching layout | Wrong files, lost position, confusing labels, and time to resume |
| Recover an interrupted action | Reload after a dropped job response and identify the outcome | Duplicate submissions, uncertainty about the saved package, and which cues helped |
| Check the context popup | Switch roles, describe which number came from the provider or an estimate, and dismiss with their preferred input | Misread totals, inaccessible focus, and any missing explanation |

Use timestamps, actions, and short observations. Keep guesses about motivation
out of the observation column. Ask what they expected after a wrong turn.
Report counts as formative observations for this small group.

Reserve one short polish slot per release. Start with the largest repeated
delay or the consequence that changes saved work. Add a focused regression
where a failure is repeatable and repeat the browser journey after the fix.
Compare against the same completion criteria and report the remaining gap.
