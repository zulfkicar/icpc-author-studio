What proves what

  • Structure: verify._structure + 16 report checks
  • Validator: verify.verify — 6/6, exit 42
  • Reference: verify.verify — AC on every test
  • Negative: verify.verify — survivor check
  • Limits: verify.measure_limits
  • Statement: verify._statement — pdflatex twice
  • Spec: icpc_spec.audit — 18/18
  • Export: verify.export_package — verified + unchanged + reviewed
  • Import: qa/test_domjudge_import.ps1
  • Judge: qa/test_domjudge_judging.ps1 — AC/WA/TLE

If asked, say this

  • “The model proposes; the verifier proves.”
  • “Export is verified, unchanged and reviewed — or it is disabled.”
  • “Secret tests go to the verifier, not to the provider.”
  • “Isolate is the authority; Judge0 is a convenience.”
  • “It is a hardened container, not a hypervisor.”
  • “The single-author loop is proven; multi-user hosting is not.”

Read in this order: verify.py → agent.py → graph_agent.py → workspace.py → isolate_worker.py.
