# Test design

1. Cover samples, boundary, random, structural, adversarial and maximum cases.
2. Use a brute-force oracle for small random stress tests.
3. Record generator seeds and commands.
4. Keep tests literal where required; generators are supporting tools.
5. Ensure every input passes the validator and every answer is generated by an accepted reference.

Output: test plan, seeds, commands, expected verdicts.
