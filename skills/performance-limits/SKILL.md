# Performance limits

1. Include worst-case size and shape tests.
2. Measure the slowest accepted reference and fastest time-limit-exceeded candidate when available.
3. Use time multipliers or the package rule; do not guess.
4. Write measured limits to metadata and statement.
5. Explain memory/time headroom and risks.

Output: measurements, chosen limits, evidence, caveats.
