# Difficulty calibration

Assess insight depth, required technique, implementation burden, edge-case density and constraint tightness. Compare against a local calibration corpus when available. Give a range and confidence, not a single fake-precise rating. Explain which factors dominate.

Output: rubric scores, range, confidence, closest calibration problems, caveats.
