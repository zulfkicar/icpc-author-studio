# Authoring workflow

Observe -> Plan -> Act -> Verify -> Record -> Review -> Deliver.

1. Inspect the workspace, statement, tests, submissions and latest report before editing.
2. Write a short todo list for the turn.
3. State intent before a batch of tool calls.
4. Make the smallest correct change.
5. Run the relevant check after each change.
6. Record decisions, assumptions and open questions.
7. Stop when verification is green, a human decision is required, or the task is blocked.

Do not repeat the same failing command blindly. Use the exact error to choose the next check.

For a new problem: constraints -> statement -> validator -> reference -> samples/secrets -> negatives -> answers -> measured limits -> verification.
